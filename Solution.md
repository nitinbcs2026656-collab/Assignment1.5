# Assignment 1.5 — GitHub Essentials II

### 1. Create Repository
Create a public repository on https://github.com/

### 2. Connect Local Project

```bash
git init
git add .
git commit -m "Initial commit"
git branch -M main
git remote add origin https://github.com/USERNAME/REPOSITORY.git
git push -u origin main
```

Replace `USERNAME` and `REPOSITORY` with your GitHub username and repository name.

### 3. Add a New File and Push

```bash
echo "# My Project" > README.md
git add README.md
git commit -m "Add README file"
git push
```

### 4. Verify
Open your GitHub repository and check the uploaded files and commit history.

**Submission:** Public GitHub repository link, for example:

`https://github.com/USERNAME/REPOSITORY`
